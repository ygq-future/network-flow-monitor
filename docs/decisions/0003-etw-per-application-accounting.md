# ADR 0003：使用 ETW 进行按应用实时计数

- 状态：已接受
- 日期：2026-08-10

## 背景

产品需要 TCP/UDP 实时按应用速率，同时不希望开发、签名和维护内核驱动。仅枚举 TCP 连接会遗漏 UDP、短连接和未启用的扩展统计。

## 决策

使用 Windows ETW 网络和进程事件，依据事件负载中的 PID 和字节大小累计每应用上下行字节。结合进程生命周期减少 PID 复用错误。

## 后果

- 不需要自定义驱动，但采集器需要适当权限。
- 必须监控 ETW 丢失事件和缓冲压力。
- 部分系统代理、宿主和无法访问进程只能归入明确的系统/未知类别，不能承诺对所有流量完美归属。
