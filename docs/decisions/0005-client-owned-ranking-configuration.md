# ADR 0005：UI 客户端拥有排行配置

- 状态：已接受
- 日期：2026-08-10

## 背景

Top N、排行窗口和显示更新周期属于用户体验配置。若服务直接维护唯一排行，多用户会话将互相覆盖配置；再暴露独立 UI 刷新率也会产生重复概念。

## 决策

采集器维护每应用累计上下行字节，并按客户端订阅间隔发送快照。每个 UI 客户端保存短期历史并按自己的窗口计算速率和 Top N。一个 `display.refresh_interval_ms` 同时表示快照周期和可见数据更新周期。

## 后果

- 不同用户可独立配置排行。
- UI 断线重连后需要重新积累足够窗口历史，在此期间明确显示“正在建立窗口”。
- UI 只在新快照或视觉状态变化时重绘，不需要持续帧循环。
