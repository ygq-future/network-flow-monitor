# ADR 0011：设置界面管理服务并隔离 UAC

- 状态：已接受
- 日期：2026-08-12

## 背景

服务安装、启动、停止和卸载会修改系统服务控制管理器状态，不能依赖 UI 进程的普通权限，也不应让 Windows 服务创建窗口。仅保留命令行入口会使已批准的双模式产品缺少正常用户入口。

## 决策

设置窗口属于普通权限的 UI 进程，负责展示配置、服务状态和错误信息。只读状态查询直接通过受限的 SCM 查询适配器完成；安装、卸载、启动、停止、重启和启动类型修改通过同一可执行文件的内部服务动作入口执行，并由 `ShellExecuteExW` 的 `runas` 动词触发明确的 UAC 提升。

服务动作入口只返回退出码和可诊断错误，不创建用户界面。UI 在动作完成后重新查询 SCM 状态；配置保存和采集器重连失败时恢复之前的运行时配置和排行状态。

## 后果

- 普通用户可以从设置界面管理服务，但系统修改仍经过 Windows 的明确同意流程。
- UI 和服务保持会话、权限和生命周期隔离，避免服务交互桌面窗口。
- 自动化测试可以使用假的设置存储和服务动作适配器验证控制器逻辑；真实 SCM/UAC 流程仍需在目标 Windows 11 主机上进行人工验收。
- 命令行服务动作是内部恢复/自动化接口，不是唯一的用户工作流。
